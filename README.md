# 🤖 ChatGPT Clone – AI Chatbot with Image Input

An advanced ChatGPT clone that supports **text and image-based conversations**, built for performance, scalability, and smooth user experience. Authenticated sessions, image support, and a fast backend make this project production-ready.

🔗 **Live Demo**: [gpt-front-two.vercel.app](https://gpt-front-two.vercel.app/)

---

## 🚀 Features

- 💬 **Text & Image Input Support**  
  Users can send both text and images in conversations, enabling rich, multimodal interactions.

- 🔒 **JWT-Based Authentication**  
  Secure login with **JWT tokens**, supporting over **1,000+ concurrent authenticated sessions**.

- ⚡ **Fast Message Retrieval with MongoDB**  
  Efficiently manages and retrieves over **50,000+ chat messages** using a MongoDB database.

- 🖼️ **ImageKit Integration**  
  Images are uploaded and embedded via **ImageKit.io** with sub-**2s load times** for optimal UX.

- 📈 **Engagement Boost**  
  Image support and chat UX enhancements led to a **25% increase in user engagement**.
